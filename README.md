# php-forms1425
PHP Form: You can generally edit it even if you don't know PHP.
======================================================================
 お問い合わせフォーム 利用マニュアル (docs.txt)
======================================================================

■ ファイル構成
----------------------------------------------------------------------
  mail-system.php  … メール送信処理・設定・完了画面・エラー画面(この1本で完結)
  sample-form.html … サイトに設置するお問い合わせフォームのサンプルHTML
  docs.txt         … このファイル(説明書)

  この2つのファイルを同じフォルダにアップロードするだけで動作します。
  例) https://example.com/contact/mail-system.php
      https://example.com/contact/sample-form.html


■ 必要な動作環境
----------------------------------------------------------------------
  ・PHP 7.4以上(mbstring拡張が有効なサーバー。レンタルサーバーであれば
    ほぼ標準で有効になっています)
  ・サーバーの mail() 機能でメール送信ができること
    (お名前.com、ロリポップ、エックスサーバー等の一般的なレンタルサーバーで動作します。
     独自にサーバーを構築している場合は sendmail 等の設定が必要です)



 1. まず最初にすること

  mail-system.php を開き、ファイル上部の「1. 基本設定」ブロックにある
  下記の項目を、ご自身の環境に合わせて書き換えてください。

  'to'          … お問い合わせを受け取りたいメールアドレス
  'from_email'  … 送信元として表示するメールアドレス
  'from_name'   … 送信元として表示する名前
  'subject'     … メールの件名
  'intro_text'  … メール本文の一番上に入れる文章

  ここまで設定すれば、フォームとしてすぐに使い始められます。




 **2. フォームの項目を自由に追加・削除する方法(PHPを触りません)**


  sample-form.html の中の <input>・<textarea>・<select> などに書かれている
  name="◯◯" の「◯◯」の部分が、そのままメール本文の【見出し】になります。

  例:
    <input type="text" name="会社名">
      → メール本文に  【会社名】 入力された内容  という形で追加されます。

  ▼ 項目を増やしたいとき
    既存の <div class="form-row">〜</div> のブロックをコピーして、
    label の文字と input の name・id を書き換えるだけでOKです。
    mail-system.php は一切編集する必要がありません。

  ▼ 項目を減らしたいとき
    該当する <div class="form-row">〜</div> のブロックを削除するだけです。

  ▼ 複数行のテキスト(textareaなど)を入力した場合
    メール本文では自動的に「見出しの次の行」に本文が表示されます。
    1行の項目(お名前・メールアドレスなど)は「見出しと同じ行」に表示されます。


 3. 必須項目・任意項目を自由に変更する方法
  必須にしたい項目は、次の2箇所を編集してください。

  ① sample-form.html の該当する input / textarea / select に
     required 属性を付ける(ブラウザ側での入力チェック用)

  ② sample-form.html の下の方にある下記の隠し項目の value に、
     必須にしたい項目の name属性をカンマ区切りで追加する
     (サーバー側での入力チェック用。①だけだと簡単に回避できてしまうため必須)

     <input type="hidden" name="_required" value="お名前,メールアドレス,チェック,お問い合わせ内容">

  ※ ①②のどちらか一方だけでも動作しますが、両方設定することを推奨します。
  ※ 任意項目にしたい場合は、required属性を外し、_required の value からも
     項目名を削除してください。


 4. 完了画面・エラー画面のデザインを変更する方法
  mail-system.php の下の方、
    「3. 完了画面・エラー画面のHTML」
  という見出しのすぐ下に、
    render_complete_screen()  … 送信完了画面
    render_error_screen()     … エラー画面
  という2つの関数があります。

  この中に書かれている <style> タグの中のCSSと、<body> タグの中のHTMLは
  すべて普通のHTML・CSSです。PHPの知識がなくても、HTML/CSSがわかれば
  文言・色・レイアウトを自由に変更できます。
  ( <?php ... ?> のような記号がある部分以外は、ほぼ全て編集して問題ありません )

 5. スパム対策(CAPTCHA)を設置する方法
======================================================================
  reCAPTCHA / hCaptcha / Cloudflare Turnstile のいずれか1つを設置できます。
  「どれか1つのシークレットキーを書くだけ」で有効になります。

  ① 使いたいサービスのサイトキー・シークレットキーを取得する
     ・reCAPTCHA v2  : https://www.google.com/recaptcha/admin
     ・hCaptcha      : https://dashboard.hcaptcha.com/
     ・Turnstile     : https://dash.cloudflare.com/ (Turnstile メニュー)

  ② sample-form.html の「スパム対策(CAPTCHA)」というコメントがある場所で、
     使いたいものの <script> と <div> のコメント( <!-- と --> )を外し、
     data-sitekey="" の中にサイトキーを入力する

  ③ mail-system.php の基本設定にある下記のいずれかに、シークレットキーを入力する
     'recaptcha_secret' / 'hcaptcha_secret' / 'turnstile_secret'

  ※ 3つとも空欄のままであれば、CAPTCHAのチェックは行われません(未使用状態)。
  ※ 2つ以上設定した場合は reCAPTCHA → hCaptcha → Turnstile の優先順位で
     どれか1つだけが使われます。


 6. その他の便利な機能
  ▼ ハニーポット(ロボット対策)
    sample-form.html には人の目には見えない入力欄(_honeypot)が
    あらかじめ用意されています。削除しないでください。
    ここにロボットが自動入力すると、メールを送らずに完了画面だけを表示し、
    静かに迷惑メールをブロックします。

  ▼ 送信者の情報が自動でメールに追加されます
    ・送信された日時 (例: 2025/02/04 (Tue) 21:39:12)
    ・送信者のIPアドレス
    は、何も設定しなくても自動でメール本文の最後に追加されます。

  ▼ 返信先(Reply-To)の自動設定
    フォームの入力内容の中にメールアドレスが含まれていた場合、
    自動的にそのアドレスが返信先(Reply-To)として設定されます。
    (メールソフトの「返信」ボタンで、そのままお客様へ返信できます)

  ▼ 自動返信メール
    mail-system.php の 'auto_reply' を true にすると、
    お問い合わせをしてくれた方へ自動でお礼メールを送信できます。
    'auto_reply_email_field' には、メールアドレスを入力する項目の
    name属性(sample-form.htmlでは "メールアドレス")を指定してください。

  ▼ 1つのmail-system.phpを複数のフォームで使い分ける
    フォームに <input type="hidden" name="_subject" value="製品Aについて">
    のような隠し項目を追加すると、メールの件名の末尾にその文言が追加されます。
    (例: 「…お問い合わせが届きました：製品Aについて」)



 7. 送信先メールアドレスについて(セキュリティ上の注意)
======================================================================
  送信先メールアドレス('to')は、セキュリティ上の理由から、
  HTML側からは変更できない仕様になっています。
  (フォームの隠し項目などで送信先を変更できる仕様にすると、
   第三者に迷惑メール送信の踏み台として悪用される危険があるためです)

  送信先を変更したい場合は、必ず mail-system.php 側の 'to' を編集してください。


 8. うまく届かないときの確認事項

  ・迷惑メールフォルダに振り分けられていないか確認する
  ・サーバーのメール送信機能(mail関数)が有効になっているか
    レンタルサーバーの管理画面・サポートに確認する
  ・'from_email' に、実際に送信可能なドメインのメールアドレスを設定する
    (全く関係のないドメインを指定すると、迷惑メール判定されやすくなります)
  ・エラー画面が表示される場合は、そこに表示されているメッセージを確認する
